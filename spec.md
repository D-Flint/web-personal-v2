# Fresh web-personal redesign v2

The [product brief](../second-brain/01-projects/web-personal-redesign-v2/PRODUCT.md) and [surface contract](../second-brain/01-projects/web-personal-redesign-v2/SURFACE.md) implement the approved Engineering Field Journal plan in a separate Astro + Tailwind + vanilla JavaScript application.

## Required behavior

- `/`: engineering-led opening, substantial selected work, factual biography and skills, resume, Web3Forms contact and compact assistant.
- `/projects`: all 20 current records; combined search/category/all-selected-technologies; persisted grid/list switching; keyboard-accessible project details; only supplied external links.
- `POST /api/chat`: existing `{ messages: [{ role, content }] }` request and plain decoded streaming chunks under the existing `text/event-stream` content type; server-only provider credentials; bounded requests, rate limits and explicit service errors.
- Custom 404; self-hosted typography; visible focus; narrow-screen layouts; mobile viewport-aware assistant.
- An interactive particle field and physical workbench span all routes. The Omarchy-inspired hero uses a large pixel-particle wordmark, dispersal/reformation and an accessible scatter control. Desk-piece collisions use a fixed step, viewport walls, weighted pair correction and adaptive substeps. Each visit varies piece placement and low-energy idle drift. Scroll velocity adds a brief bounded physical nudge, with a smaller depth shift tied to progress. Protected content fades nearby elements smoothly without repositioning them, including during drag/release. Geometry refresh is coalesced per frame and resizing preserves/clamps the existing scene. Reduced motion is static; the frame loop runs continuously while visible and stops while hidden; hero motion pauses offscreen.

## User feedback incorporated

The first catalog retained too much of the old card grid. The new archive uses a desktop filter sidebar, wide editorial record rows and a distinct text-led grid alternative. The initial particle field and proposed generic traces/mesh were rejected; the subsequent mechanical-arm version was also rejected. The user selected “Playful interactions with physical objects”; the workbench followed. On 2026-10-13 the user requested restored interactive particles, improved collisions and an Omarchy-like opening; this supersedes the earlier particle rejection.

The later motion request extends the background beyond the opening viewport. Scrolling now opens the architecture studies into exploded diagrams with attached wires, rather than revealing hidden content. Mobile retains readable nodes and connecting arrows; reduced motion preserves the assembled study.
